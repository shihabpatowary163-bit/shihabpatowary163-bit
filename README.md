## 🚀 Featured Networking Projects

### 1. Secure Enterprise Banking Network Infrastructure

**Tools & Technologies:** Cisco Packet Tracer, VLAN, OSPF, HSRP, ACL, STP, LACP

This academic project focused on designing and simulating a secure network infrastructure for a multi-branch banking environment.

The main challenge was to organize network communication while considering security, availability, and reliable connectivity between different parts of the organization.

**Key areas covered:**
- Three-tier hierarchical network architecture
- VLAN configuration and IP subnetting
- Inter-VLAN routing
- OSPF dynamic routing
- HSRP gateway redundancy
- Extended Access Control Lists (ACLs)
- Rapid-PVST+ and LACP EtherChannel

### 2. Enterprise Network Design Using BGP-4 and DiffServ QoS

**Tools & Technologies:** Cisco Packet Tracer, BGP-4, eBGP Multihop, VLAN, DiffServ, LLQ

This project explored enterprise network connectivity, routing, and traffic management using BGP and Quality of Service mechanisms.

I worked with different networking concepts to understand how routing decisions and traffic prioritization affect communication across an enterprise network.

**Key areas covered:**
- BGP-4 and eBGP Multihop
- VLAN and Inter-VLAN Routing
- DiffServ Quality of Service (QoS)
- Low Latency Queuing (LLQ)
- DMZ network design
- Network failover and troubleshooting

**Research Title:**
